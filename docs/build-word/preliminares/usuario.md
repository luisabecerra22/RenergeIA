# INTRODUCCIÓN

El presente Manual de usuario explica, módulo por módulo, el uso de la plataforma RenergeIA del Grupo Renergeia para la gestión de proyectos solares fotovoltaicos EPC.

Cada capítulo sigue la misma estructura: para qué sirve el módulo, conceptos clave, cómo funciona, paso a paso, qué hacer en caso de problemas, relación con otros módulos y buenas prácticas. Los nombres de botones y pestañas aparecen en **negrita**, tal como se ven en la pantalla.

La plataforma está disponible en https://renergeia-web-577313322290.us-central1.run.app y se usa desde Chrome o Edge.

# OBJETIVO

Orientar a las personas que usan RenergeIA en el registro, consulta y análisis de la información de los proyectos, de manera que los datos se carguen una sola vez, sin duplicados, y que todas las pantallas muestren cifras coherentes.

- Explicar el propósito y el funcionamiento de cada módulo.
- Describir paso a paso las tareas habituales.
- Indicar qué hacer ante los mensajes y problemas más frecuentes.
- Mostrar cómo se relacionan los módulos entre sí.

# ALCANCE

Este Manual aplica a todos los módulos de la plataforma RenergeIA: proyectos, cronograma de actividades, informe diario, documentos, costos, histogramas, HSEQ, control de ingreso, alertas, clima, dashboard, centro de control, compromisos y el panel del asistente Helvis. Incluye una referencia a la plataforma de Evaluaciones HSE, que es una aplicación independiente.

Está dirigido a todas las personas que usan la plataforma: dirección y gerencia de proyectos, planeación, obra, costos, control documental y equipos HSEQ. Los aspectos técnicos (código, base de datos y despliegue) no forman parte de este Manual.

# DEFINICIONES

| Término | Definición |
|---|---|
| **Actividad hoja** | Actividad del cronograma que no tiene subactividades; es la que se usa en los cálculos de avance. |
| **Cronograma vigente** | Versión del cronograma marcada como vigente; alimenta el dashboard, la Curva S y los informes. |
| **Curva S** | Gráfica del avance acumulado programado frente al real. |
| **Brecha** | Avance real menos avance programado, en puntos porcentuales. |
| **Presupuesto base** | Oferta económica del proyecto, usada como referencia de costos. |
| **Seguimiento de pagos** | Archivo semanal con órdenes de compra, pagos realizados y programados. |
| **Ejecutado** | Lo pagado hasta la semana anterior a la actual. |
| **Comprometido** | Lo programado para pagar desde la semana en curso. |
| **Planificación documental** | Formato FO-SI-GC-002-1 con los documentos del proyecto y su estado. |
| **Papelera** | Lugar donde quedan los proyectos eliminados, desde donde pueden restaurarse. |
